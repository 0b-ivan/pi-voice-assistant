# Schola

`schola-regular.woff2` and `schola-bold.woff2` are TeX Gyre Schola (GUST e-foundry),
a free Century Schoolbook: the face the community identified on the Adeptus
Mechanicus transfer sheets. Taken from Debian's `fonts-texgyre` (20180621) and
subset to Latin-1 plus typographic punctuation with fontTools (`pyftsubset
--flavor=woff2`), otherwise unchanged. Licence: GUST Font License
(`GUST-FONT-LICENSE.txt`), an instance of the LaTeX Project Public License 1.3c.

# Share Tech Mono

`share-tech-mono.woff2`: Share Tech Mono by Carrois Type Design, Latin subset
from `@fontsource/share-tech-mono` 5.3.0, unchanged. Licence: SIL Open Font
License 1.1 (`OFL-share-tech-mono.txt`). Used for the teleprinter text.

# Pixelify Sans

`pixelify-sans-400.woff2`, `pixelify-sans-700.woff2`: Pixelify Sans, Latin
subset from `@fontsource/pixelify-sans` 5.3.0, unchanged. Licence: SIL Open
Font License 1.1 (`OFL-pixelify-sans.txt`). Used for the HUD lettering.
